# PRIMA — сфероїдична геодезія (порт на Go)

[![Test](https://github.com/white-collar/prima-go/actions/workflows/test.yml/badge.svg)](https://github.com/white-collar/prima-go/actions/workflows/test.yml)

[English](README.md) | **Українська**

Переписана на Go програма `PRIMA.EXE` — DOS-програма *«Решение задач сфероидической геодезии»*
(Розв'язання задач сфероїдичної геодезії). Оригінал — програма на Borland Pascal 7 (1992),
що використовує **еліпсоїд Красовського 1940 року**. Усі формули відновлено з машинного коду
виконуваного файлу, а результати перевірено порівнянням з оригіналом, запущеним у DOSBox-X
(див. [Перевірка](#перевірка-порівнянням-з-оригіналом)).

## Автори оригінальної програми

Оригінальну програму написали студенти-геодезисти як навчальний проєкт
(імена наведено так, як вони записані в програмі):

| Роль | Автор |
|---|---|
| Автор інтерфейсу та більшості підпрограм | **Бартенева А.В.**, група ПГ-90 |
| Автор окремих підпрограм | **Воронова В.И.**, група ПГ-88 |
| Автор окремих підпрограм | **Котолуп Т.Ф.**, група ПГ-88 |
| Керівник роботи | **Гавриленко Ю.Н.**, доктор наук, професор кафедри геоінформатики і геодезії [Донецького національного технічного університету (ДонНТУ)](https://donntu.edu.ua) |

Алгоритми та структура програми належать їм; цей репозиторій — перенесення на Go,
зроблене з навчальною метою. Оригінальний виконуваний файл сюди не входить.

## Запуск

```bash
go run ./cmd/prima
```

```bash
go test ./geodesy -v
```

Кути вводяться як `Г Х С` (градуси, хвилини, секунди: `55 45 20.5`); одне число означає десяткові градуси.

## Структура

| Файл | Що містить | Пункт меню оригіналу |
|---|---|---|
| `geodesy/ellipsoid.go` | константи, V, W, N, M, R, r, R_A | Радиусы кривизны |
| `geodesy/arcs.go` | дуга меридіана (коротка формула та повний ряд), дуга паралелі | Длины дуг |
| `geodesy/trapezoid.go` | площа трапеції та рамка аркуша карти | Площадь / рамки трапеций |
| `geodesy/problems.go` | пряма задача (Шрейбер, Рунге–Кутта–Мерсон), обернена задача (формули із середніми аргументами) | Главные геодезические задачи |
| `geodesy/gauss.go` | Гаусс–Крюгер в обидва боки, зближення меридіанів, поправки за перехід з еліпсоїда на площину | Перевычисление координат |
| `cmd/prima/main.go` | інтерактивне меню з такою самою структурою, як в оригіналі | — |
| `tools/re/` | скрипти, якими формули витягнуто з `PRIMA.EXE` | — |
| `tools/dosbox/` | засіб, що запускає `PRIMA.EXE` у DOSBox-X і порівнює його з портом на Go | — |

У коментарі до кожної функції вказано відповідну процедуру оригіналу, наприклад `orig 2821:0573`.

## Відмінності від оригіналу

Обчислення збігаються з оригіналом. Свідомі відмінності:

- **Немає файлів даних і табличного редактора.** Оригінал зберігав таблиці вхідних даних у файлах `*.LB1`…`*.LBB`. Ця версія — проста консольна програма «питання — відповідь».
- **Перехід з площини на еліпсоїд зберігає знак y.** Оригінал передавав `|Y − Y0|`, тому `l` завжди виходило додатним. Цей порт також виводить `L = L0 + l`.
- **Метод Рунге–Кутта–Мерсона може робити кілька кроків.** Оригінал робить один крок на всю лінію. `DirectRKM(..., steps)` дає змогу розбити лінію на частини; меню, як і оригінал, використовує 1 крок.
- **Одиниці в бібліотеці.** `ReductionToPlane` приймає метри; екран меню, як і в оригіналі, приймає кілометри.
- **Захист від ділення на нуль.** Якщо y_m = 0, поправки дорівнюють 0; оригінал у цьому разі завершувався з помилкою виконання.

Ці особливості оригіналу збережено, щоб числа не змінилися; у коді біля кожної з них є коментар:

- підпрограма Рунге–Кутта використовує скорочене значення e'² = 0.00673853;
- в оберненій задачі коефіцієнт Q записано як `(1 − 9e'²) + 8η²`;
- підпрограма зближення меридіанів спочатку обчислює ряд, а потім перезаписує результат формулою в замкненому вигляді. Підручниковий ряд винесено окремо у функцію `ConvergenceSeries`.

## Як було відновлено код (`tools/re`)

1. **Заголовок MZ.** `PRIMA.EXE` — 16-бітний виконуваний файл DOS. `mz.py` розбирає його заголовок і сегменти.
2. **Емуляція чисел з плаваючою комою.** Turbo Pascal компілює обчислення з плаваючою комою у виклики `INT 34h…3Dh` до свого емулятора 8087. `fix.py` перетворює їх назад на справжні інструкції x87.
3. **Константи.** Вони зберігаються в коді як 10-байтові значення `Extended`, наприклад `6399698.9018`, `0.0067385254`, `6367558.4969`.
4. **Формули.** `sym2.py` символьно проходить операції зі стеком x87 у процедурі й виводить формули на кшталт `v28 := (1 - ((va * va) / 6)) * v14`.

## Перевірка порівнянням з оригіналом

`tools/dosbox/compare.py` запускає `PRIMA.EXE` у DOSBox-X і вводить тестові рядки з `cases.py` на кожен екран. Потім зчитує кожну таблицю результатів і порівнює її з портом на Go.

Оригінальною програмою керує `feeder.asm` — невелика резидентна програма DOS. Вона відповідає на запити клавіатури оригіналу (BIOS `INT 16h`) натисканнями зі сценарію і в позначених місцях зберігає текстовий екран у файл.

**Результат.** 47 тестових рядків на всіх 13 екранах збігаються в межах округлення, з яким оригінал виводить числа: не більше 0.0005 в останньому показаному розряді (0.001″, 0.001 м) і 0.005 км² на екрані площі, де виводяться два знаки після коми.

Вимоги: покладіть свою копію `PRIMA.EXE` у корінь репозиторію (тут вона не поширюється)
і встановіть DOSBox-X та nasm. Скриптам у `tools/re` вона теж потрібна.

```bash
brew install dosbox-x nasm
```

```bash
python3 tools/dosbox/compare.py
```
